# Taylor Swift — Hành trình âm nhạc

A responsive Vietnamese-language React website summarizing Taylor Swift's career,
albums, milestones, image credits, and editorial sources.

## Run locally

Install dependencies and start the Vite development server:

```sh
npm install
npm run dev
```

Create and preview a production build:

```sh
npm run build
npm run preview
```

The app uses React Router routes for the overview, career timeline, albums,
milestones, and sources pages.
